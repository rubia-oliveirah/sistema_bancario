# Sistema Bancário em C

## Sobre o projeto
Simulador de caixa eletrônico desenvolvido em linguagem C como projeto de aprendizagem de Algoritmos e Pensamento Computacional.

## Funcionalidades
- Consulta de saldo
- Depósito de valores
- Saque com verificação de saldo disponível
- Validação de opções do menu
- Exibição do saldo final ao encerrar

## Tecnologias utilizadas
- Linguagem C
- Entrada e saída de dados com `scanf` e `printf`
- Estruturas condicionais (`if/else` e `switch`)
- Laço de repetição (`do-while`)

## Como executar
Compile o arquivo `main.c` com um compilador C, como o GCC:

```bash
gcc main.c -o sistema-bancario
```

Execute o programa:

```bash
./sistema-bancario
```

No Windows, dependendo do terminal, execute `sistema-bancario.exe`.

## Objetivo
Praticar variáveis, estruturas condicionais, laços de repetição e validação de dados em C.
